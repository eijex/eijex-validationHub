# Confidentiality Guardrails

ValidationHub accepts only non-confidential wet-lab feedback summaries.

Do not store patient data, clinical subject data, confidential partner/customer information, private customer names, respondent identity, raw sequence data, proprietary constructs, internal batch IDs, exact confidential process parameters, confidential assay protocols, or unpublished construct-identifying labels.

Any record containing prohibited data must be rejected or redacted before curation. Rejected raw records must not be committed to this repository.

Public summaries require optional public-summary consent and manual review.
