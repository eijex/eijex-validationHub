# Google Forms Privacy

This scaffold assumes Google Forms automatic email collection, response summaries, file uploads, and response editing are disabled.

Required Google Forms posture:

- Do not collect email addresses automatically.
- Do not allow file uploads.
- Do not publish response summaries.
- Do not allow response editing.
- Do not request raw sequences, confidential construct details, patient data, respondent identity, private contact information, internal batch IDs, or exact confidential process parameters.
- Use protein class instead of protein name by default.
- Include required consent checks and optional public-summary consent.

The user will update Google Survey and Google Forms settings separately. This repository does not connect to Google Forms in the current scaffold.
