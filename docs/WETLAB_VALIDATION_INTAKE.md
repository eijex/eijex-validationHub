# Wet-Lab Validation Intake

This scaffold defines a safe intake shape for non-confidential wet-lab feedback.

Default public-safe fields include FactorForge version, host organism, optimization profile, protein class, assay type, harvest timepoint, replicate category, comparison result, expression result, approximate yield range, consent flags, and non-confidential notes.

Do not request raw sequences, exact confidential process parameters, respondent identity, internal batch IDs, confidential customer/partner information, or patient data.

Private records are local-only placeholders in the current scaffold. Do not process real survey exports yet.
