# ID Policy

This scaffold uses non-identifying internal UUID-style IDs only for local placeholder records.

Do not use `Construct ID` as a label. Use `Non-confidential construct alias` with internal field name `non_confidential_construct_alias`.

The alias must not contain internal batch IDs, customer construct IDs, plasmid IDs, proprietary construct names, unpublished construct-identifying labels, or sequence-derived identifiers.

Public summaries use `public_validation_id` such as `FF-WL-2026-001`.
